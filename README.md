# Ligne SQL

Révision SQL / MySQL en 8 jours, pensée pour le téléphone et utilisable hors ligne.

**En ligne :** https://ioulianlc.github.io/revision-sql/

## Contenu

- **Plan** : 8 jours × 3 créneaux (trajet du matin, trajet du soir, PC le soir).
- **Cours** : 12 modules (bases, clés, Merise, DDL, DML, SELECT, fonctions, agrégats, jointures, sous-requêtes et UNION, administration, TP corrigé).
- **Cartes** : flashcards en répétition espacée (boîtes de Leitner).
- **Jeux** : « Reconstruis la requête » (57 puzzles en 6 tronçons, avec blocs intrus et étoiles), quiz, « Prédis le résultat », « Trouve l'erreur », « Remets dans l'ordre », sprint Vrai/Faux, examen blanc.
- **PC** : exercices MySQL corrigés sur les bases `subways` et `bibliotheque`, plus un sujet blanc.

## Installer sur iPhone (hors ligne)

1. Ouvrir l'adresse ci-dessus dans **Safari**, avec du réseau.
2. Partager → **Sur l'écran d'accueil**.
3. Lancer l'appli une fois depuis l'icône. Ensuite, elle fonctionne en mode avion.

## Fichiers

| Fichier | Rôle |
|---|---|
| `index.html` | L'application (HTML, CSS et JS dans un seul fichier) |
| `sw.js` | Service worker : cache hors ligne |
| `manifest.webmanifest` | Installation sur l'écran d'accueil |
| `bibliotheque.sql` | Base d'entraînement MySQL |
| `fiche-revision-sql.md` | Fiche de révision condensée |
